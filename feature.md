# Feature: Clickable Index Chips → Detail Page

## What (user story)

Each chip in the dashboard's indices bar is a link to that ticker's stock
detail page (`/stock/<symbol>`) — the same destination the search dropdown,
watchlist rows, and ledger ticker links already use.

## Decisions (from planning + user approval)

- **Real `<a>` anchors, not JS click handlers.** The ledger ticker-link
  comment (main.js:645) already established the rule: a real `<a>` gives
  native middle-click / open-in-new-tab / keyboard Enter / hover-URL-preview
  for free. Watchlist rows need a JS handler only because JS rebuilds them
  every 60s; chips are static HTML, so a plain anchor is the natural fit.
- href is generated by `{{ url_for('stock_page', symbol='...') }}` — Flask
  percent-encodes `^GSPC` → `/stock/%5EGSPC` (`^` is illegal raw in URLs;
  `BTC-USD` is URL-safe already), and Flask decodes it back on the way in.
  The route's `.strip().upper()` normalizes the symbol as always.
- **Zero JS changes:** `updateChip`, `setChipState`, and the gap-fill query
  `.chip[data-symbol]` and touch only the child spans (main.js:14-71) —
  tag-agnostic.
- CSS: `.chip` gains `color: inherit; text-decoration: none;` plus a
  hover/focus-visible affordance consistent with the sortable headers.
- No backend changes.
