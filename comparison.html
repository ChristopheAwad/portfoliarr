Best For

Portfoliarr

  • Learning project — understand every layer of the stack
  • Single person tracking a personal portfolio
  • CAD-focused Canadian investor
  • Zero-config, minimal infra (SQLite, no Redis/Postgres)
  • Want a lean, hackable codebase you fully own
  • Prefer vanilla JS over framework complexity

Ghostfolio

  • Multi-broker, multi-account consolidation
  • Dividend, bond, and wealth-item tracking
  • Portfolio risk analysis (X-ray, benchmarks)
  • Multi-user households or financial advisors
  • Want a polished PWA with 10-language support
  • Prefer a battle-tested app with 9k+ GitHub stars
