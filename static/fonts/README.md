# Local fonts

These are the normal variable faces returned by the existing Google Fonts
request for Fraunces optical sizes 9-144 and weights 400-700, and Instrument
Sans weights 400-700. The CSS keeps the upstream unicode ranges and
`font-display: swap`. The font files are not modified.

CSS source: <https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400..700&family=Instrument+Sans:wght@400..700&display=swap>
