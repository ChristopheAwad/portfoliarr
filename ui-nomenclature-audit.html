1. Critical Incorrect / Non-Standard Financial Terminology

1.1 “Total Gain” / “Day Gain” → Should be “P&L” or “Return”

CurrentIndustry StandardUsed In
Total GainTotal P&Lledger.html:220, preferences.html:42
Total Gain %Total Return %ledger.html:224, preferences.html:43
Day GainDay Changeledger.html:227, preferences.html:44
Day Gain %Day Change %ledger.html:230, preferences.html:45

“Gain” implies only positive outcomes. The industry universally uses “P&L” (Profit & Loss), “Return”, or “Gain/Loss” to cover both directions. Schwab uses “Day Change” and “Total Return”.

“Value” alone is ambiguous — it could mean cost basis, market value, or intrinsic value. Schwab and Fidelity both use “Market Value”.

“Qty” is a database column name, not a user-facing label. Schwab uses “Quantity”, Robinhood uses “Shares”.

2. High Inconsistent Vocabulary

2.1 “Ledger” page heading says “Transactions”

The nav says Ledger but the page <h3> says Transactions (ledger.html:33). The page heading should match the nav item.

Recommendation: Change <h3>Transactions</h3> to <h3>Ledger</h3>.

6. Prioritized Change List

Must Fix Financial Accuracy

  1. Total Gain / Day Gain → Total P&L / Day P&L (or Total Return / Day Change)
  2. Realized → Realized P&L
  3. Value column → Market Value
  4. Unify return vocabulary: pick Return % OR P&L %, use everywhere
  5. 52W Range → 52-Wk Range
  6. Qty → Quantity
  7. Avg cost → Avg. Cost

Should Fix Professional Polish

  1. Fix “Ledger” page heading Transactions → Ledger
  2. Log button → Record
  3. Remove HTTP status codes from error messages
  4. None (backend order) → Default (by date)
  5. Show USD in USD → Display in original currency
  6. Div Yield → Dividend Yield
  7. Analyst Target → Target Price
  8. Default sort → Default Sort Order

Nice to Have Polish

  1. Improve all empty state messages to be instructional
  2. Remove “is it running?” from all network errors
  3. txn/txns → transaction/transactions
  4. Rating → Analyst Rating
  5. Main badge → Primary or remove
  6. Unify privacy toggle: Hide values / Show values
  7. Show closed positions → Include closed positions
